# SkillBridge 

SkillBridge is a full-stack learning platform that helps users learn new skills through structured roadmaps, interactive lessons, practice activities, progress tracking, and achievement badges.

It also provides an **Admin Dashboard** for managing users and learning content.

---

##  Features

###  User Features

- User registration and login
- Personalized dashboard
- Learning roadmaps
- Levels and lessons
- Interactive questions
- Practice Hub
- Progress tracking
- Achievement badges
- User profile

###  Admin Features

- Admin login
- Admin dashboard
- User management
- Roadmap management
- Level management
- Lesson management
- Lesson question management
- Practice question management

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- MySQL

### 1. Clone the Repository

```bash
git clone <repository-url>
cd SkillBridge
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Install Backend Dependencies

```bash
cd ../backend
npm install
```

### 4. Setup MySQL Database

Create the database:

```sql
CREATE DATABASE skillbridge;
```


### 5. Run the Backend

```bash
cd backend
node filename.js
```

### 6. Run the Frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

Open the Vite URL shown in your terminal.
